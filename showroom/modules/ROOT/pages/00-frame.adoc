== Show

Turn an ambiguous “AI agent” claim into six responsibilities you can inspect.

== Learn

An agentic workflow is not merely a prompt that calls a tool. Useful agency requires explicit separation between planning, tool access, evidence, policy, and authority.

== Do

Create your workflow map and predict what should happen for the two requests.

----
