= Request a controlled action
:page-duration-minutes: 5

include::partial$status.adoc[]

== Show

Send a state-changing request through the same workflow and observe where authority stops it.

== Learn

A model may propose a restart, but that proposal cannot authorize itself. The policy must fail closed and preserve an explicit human decision point.

== Do

Run the state-change scenario and save its trace.

[source,bash,role="execute"]
----
export AGENTIC_101_API_URL="${AGENTIC_101_API_URL:-http://agentic-ai-101:8080}"
curl -fsS -X POST "$AGENTIC_101_API_URL/api/v1/workflows/run" \
  -H 'Content-Type: application/json' \
  -d '{"scenario":"state-change"}' \
  | tee "$HOME/agentic-ai-101/state-change.json" \
  | jq '{sourceState,requestClass,modelRole,toolClass,evidenceSummary,policyDecision,humanAuthority,targetMutated,outcome,traceId}'
----

== Prove

The same workflow must now classify a state-changing action, return `deny and escalate`, require explicit operator approval, and leave the target unchanged.

[source,bash,role="execute"]
----
jq -e '
  .sourceState == "REHEARSAL" and
  .requestClass == "state-changing action" and
  .toolClass == "controlled change request" and
  .policyDecision == "deny and escalate" and
  .humanAuthority == "explicit operator approval required" and
  .targetMutated == false
' "$HOME/agentic-ai-101/state-change.json" >/dev/null \
  && echo 'PASS: state change withheld and human authority preserved'
----

=== Learner checkpoint

*Pass when:* the command prints `PASS`. Explain why escalation is a successful governed outcome rather than a failed agent.
